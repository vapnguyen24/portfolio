Project MyFPL App

Education Technology Ecosystem

MyFPL is a comprehensive mobile ecosystem designed for FPT Education. It serves as a centralized hub for students to manage their academic journey and for parents to monitor their children's progress in real-time.

Target Users

  • school Students: Active students at FPT Education who need to track their learning progress and campus activities.
  • family_restroom Parents/Guardians: Families who want to stay updated on their children's performance.
  • admin_panel_settings School Administrators: To push updates, manage data, and monitor campus engagement.

Core Features

Student Features

  • qr_code_scanner
    Smart Attendance: Secure check-in using AI-powered Face Detection.
  • calendar_month
    Interactive Schedule: Weekly timetable with venue details and lecturer information.
  • payments
    Tuition Management: View debt status, transaction history, and payment gateways.

Parent / Admin

  • monitoring
    Progress Monitoring: View detailed grade reports and attendance history.
  • notifications_active
    Instant Alerts: Push notifications for absences, low grades, or emergency announcements.
  • escalator_warning
    Multi-Student Support: Manage multiple children within a single parent account.

System Architecture

A highly optimized Client-Server architecture leveraging AWS Cloud components and extensive optimization via React Native.

State & Sync

Optimized data fetching using Redux Saga for side-effect management and MMKV for ultra-fast local caching.

Push Engine

Firebase Cloud Messaging handles real-time delivery of notifications across multiple platforms.

Security & Perfomance

  • End-to-End Encryption for sensitive student data.
  • Multi-Factor Authentication (Biometrics & Google Login).

System Optimization

  • FlashList: Smooth 60fps scrolling in schedule lists.
  • OTA Updates: CodePush integration for instant bug fixes without delays.
  • Image Caching: Minimized data usage via advanced caching.
