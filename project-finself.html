Project Finself

Your Financial Self-Management Companion

Finself is a comprehensive financial self-management application designed to empower individuals with full control over their financial health. It combines intuitive expense tracking with powerful budgeting tools and deep financial insights.

  • check_circle Value for Users: Improved financial literacy, better savings habits, and a stress-free way to manage wealth.

Clean Architecture

Following the Clean Architecture principles, ensuring a strict separation of concerns between business logic, data management, and the user interface.

wallpaper Presentation Layer

UI components and robust state logic powered by Riverpod.

account_tree Domain Layer

Business logic and entity definitions encapsulating core application rules.

storage Data Layer

Repository implementations, remote API clients (Dio), and local storage (Hive).

Security & Perfomance

  • verified_user Complete Authentication: Secure login via Firebase Auth (Email, Google, Apple ID).
  • lock Data Protection: All sensitive user data is encrypted at rest and in transit (HTTPS/SSL).

Optimization Techniques

  • Efficient Caching: Hive is used for lightning-fast local data retrieval.
  • State Efficiency: Selective rebuilding of UI components using Riverpod's reactive system.
  • Perceived Performance: Shimmer Effects during data fetching.

Application Interface

Modern, clean UI/UX designed with a "Mobile First" approach based on strictly adhered Material Design 3 guidelines.
